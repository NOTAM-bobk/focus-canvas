# focus-canvas

A customizable productivity canvas — drag, resize, and stack widgets on a themed board, or use the mobile-friendly card layout on phones.

## Features

- **Timers & focus** — pomodoro-style focus timer, interval timer, and stopwatch with a persistent dock.
- **Planning** — task list with progress bar, weekly habit tracker, and event countdown.
- **Wellbeing** — hydration tracker, rotating inspiration quotes, and an ambient soundscape player (white / pink / brown / rain).
- **Utilities** — live clock, notes scratchpad, quick links, and a daily stats summary.
- **Personalisation** — accent presets, custom canvas background, light/dark themes, grid overlay, and layout reset. Everything is persisted in `localStorage`.

## Development

```bash
bun install
bun run dev      # http://localhost:3000
bun run build    # static output in dist/
```
